# React Mapbox App

This is a sample React application with Mapbox map initialization.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Get a Mapbox access token from [mapbox.com](https://account.mapbox.com/access-tokens/) and replace `YOUR_MAPBOX_ACCESS_TOKEN` in `src/App.tsx`.

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

To build the app for production:
```bash
npm run build
```

## Technologies Used

- React
- TypeScript
- Vite
- Mapbox GL JS
- react-map-gl
